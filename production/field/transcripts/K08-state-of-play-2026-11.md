ALEX: So it's "according to Menlo, an Anthropic investor", every time.

SAM: Every time. Menlo also puts Claude Code and Codex together at seventy percent of a thirty-four-billion-dollar coding market, without splitting them, and open-weight models at nineteen percent of tokens but four percent of spend.

ALEX: Second source?

SAM: Stack Overflow's twenty twenty-six developer survey, published October sixth, over thirty thousand respondents. Claude Code is the most-used coding agent, at sixty-six percent of developers who use A I, with GitHub Copilot at fifty-nine.

ALEX: Third?

SAM: Open Router's rankings, thirty days to November thirteenth. By request share, DeepSeek leads at about thirty-two percent; Anthropic is fifth, under six.

ALEX: Open Router is hobbyists running agent loops on cheap models. I'd ignore it.

ALEX: The tell?
